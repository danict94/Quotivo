# Avvio locale

Questa è la prima base mobile di Quotivo.

```bash
cd quotivo-mobile
npm install
npx expo start
```

Poi apri il progetto con Expo Go scansionando il QR code, oppure usa `a` per Android, `i` per iOS e `w` per il web.

La schermata attuale è un prototipo interattivo: dashboard, archivio, numerazione progressiva dimostrativa e impostazioni. Il salvataggio reale, i template e il motore di esportazione arriveranno negli scope successivi.
