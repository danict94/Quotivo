# Documentazione canonica

Questa cartella, interna alla radice Git `quotivo-mobile`, è la copia canonica della documentazione di Quotivo dal presente scope.

I file omonimi nella cartella esterna `../docs` e `../AGENTS.md` sono stati lasciati intenzionalmente al loro posto per non cancellare automaticamente materiale dell'utente. Possono essere considerati copie storiche e non devono essere aggiornati in parallelo. I riferimenti futuri devono puntare a:

- `AGENTS.md` nella radice Git;
- `docs/quotivo-brief.md`;
- `docs/ARCHITECTURE.md`;
- `docs/ROADMAP.md`;
- `docs/HANDOFF.md`;
- `docs/AUDIT-PREVENTIVI.md`.

La rimozione delle copie esterne resta una scelta esplicita dell'utente.
